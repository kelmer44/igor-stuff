Read [REPORT.md](REPORT.md) for the results, scope and limitations.
The engine source is unchanged. The completed audit snapshot is

## Reproduce the static checks

From `/Users/gabriel/Desktop/source/igor-stuff`:

```sh
python3 audit/2026-10-15/re-audit/check_assets.py
python3 audit/2026-10-15/re-audit/check_actions.py
python3 audit/2026-10-15/re-audit/check_text_native.py
```

The native instruction check uses the installed Capstone module. The catalog
and action checks use Python's standard library. `evidence/assets.json` includes
all input hashes and the current revision. `evidence/actions.json` is a
conservative table scan, not a normal-gameplay reachability proof.

The dictionary was generated by compiling the unmodified
`reference/scummvm-create-igortbl/create_igortbl.cpp`, then running the resulting
tool **inside `evidence/`**, so installed dictionaries were not overwritten.
The output is `evidence/IGOR.TBL`; comparisons are recorded in
`evidence/tbl-reproduction.json`.

## Reproduce runtime checks

Build and link the current fork first:

```sh
make -C /Users/gabriel/Desktop/source/scummvm-fork engines/igor/libigor.a scummvm -j4
```

Each of `runtime`, `text-runtime`, `save-runtime`, `options-runtime`,
`exit-runtime`, and the subdirectories under `regressions` contains a `build.sh`
and `run.py`. Build the injected driver, then run the runner, e.g.:

```sh
sh audit/2026-10-15/re-audit/runtime/build.sh
python3 audit/2026-10-15/re-audit/runtime/run.py
```

The suites use SDL dummy video/audio, original assets, the installed TBL and
isolated configuration/log/save directories. They exercise real engine methods
on the main thread. Some supply controlled state; the report distinguishes
those fixtures from normal input or a complete playthrough.

`generate_runtime.py` regenerates the broad loader matrix from current catalogs
and source room-resource calls. `evidence/runtime-summary.json` indexes markers
from the completed runs. Detailed stdout/stderr and engine logs remain in each
suite directory. The tests are not a substitute for a synchronized DOS run or
an instrumented full puzzle playthrough.
